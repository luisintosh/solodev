# fixture-repo

Tiny Node project used as a local smoke-test fixture. Not part of the published toolkit.

## Commands

- install: `npm install`
- dev: `npm run dev`
- build: `npm run build`
- test: `npm test`
- test_file: `npx vitest run {file}` (one test file)
- lint: n/a (no linter configured)
- typecheck: n/a (plain JS)

See `docs/ARCHITECTURE.md` when it exists; tests live next to source as `*.test.js`, using `vitest`.
